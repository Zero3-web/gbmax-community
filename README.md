# MAX Community

Una demostración abierta de interfaz para una plataforma de películas y series. Incluye una landing responsive, catálogo de ejemplo, perfiles locales y una experiencia de navegación pensada para TV.

> No incluye películas, enlaces de reproducción, proveedores, cuentas reales, analítica, cobros, infraestructura ni secretos. Úsalo únicamente con contenido que tengas derecho a distribuir o reproducir.

## Ejecutar localmente

No requiere dependencias. Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático.

```sh
npx serve .
```

## Qué es público

- Diseño de la landing y navegación de muestra.
- Datos ficticios para el catálogo.
- Patrones de accesibilidad y control remoto/teclado.

## Qué no forma parte de este repositorio

- Credenciales, archivos `.env`, certificados, tokens o claves API.
- Código de despliegue y administración de producción.
- Integraciones de reproducción, proveedores o servicios internos.
- Datos de usuarios, pagos, métricas y contenido comercial.
