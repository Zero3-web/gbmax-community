# Código de conducta

Nos comprometemos a mantener un espacio respetuoso, inclusivo y constructivo.

No se toleran acoso, ataques personales, discriminación, publicación de información privada ni el uso del proyecto para distribuir contenido no autorizado. Los mantenedores pueden editar o retirar contribuciones que incumplan estas reglas.

Para reportar una situación delicada, usa el canal privado indicado en `SECURITY.md`.
